HB PORTFOLIO - MEDIA SLOTS
=========================

Drop your own files into this folder using EXACTLY these names. Anything missing silently falls back
to the generated cinematic placeholder, so you can add files one at a time.

SHOWREEL (hero, full-bleed, muted loop; also opens in the player with sound)
  reel.mp4   - H.264 MP4, 1920x1080 or 2560x1080 (2.39:1), 20-40 s, under ~20 MB, no audio needed
  reel.jpg   - poster frame, 1920x1080 JPG

TO RENAME OR ADD ITEMS
  Edit the MEDIA object at the top of the <script> in index.html (paths) and the WORKS array just below
  it (title, client, year, category, roles). Titles/clients in WORKS are placeholders until confirmed.

TIPS
  - Keep card videos short (6-10 s loops); the player plays the same file, so one file per item is enough.
  - Videos must be H.264/AAC MP4 to play in every browser, including Safari.
