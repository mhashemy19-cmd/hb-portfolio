Privacy Policy — Story Channel

Last updated: 4 November 2026

Story Channel is a private tool operated by Mohammad Hashemi (HB Studio). It prepares videos and uploads them to the operator's own YouTube channel using the YouTube API Services. It is not offered to the public and has no other users.

Data we access

With the operator's explicit Google authorization, the tool can upload videos to, and read basic information about, the operator's own YouTube channel (for example video titles, descriptions and status). It does not access any other person's data.

How data is used

Access is used only to upload and manage the operator's own videos. Authorization tokens are stored securely by the connection provider and are used only for that purpose.

Sharing

We do not sell, rent or share Google user data with third parties, and we do not use it for advertising.

YouTube API Services

The tool uses YouTube API Services and is subject to the YouTube Terms of Service and the Google Privacy Policy.

Revoking access and deletion

Access can be revoked at any time at myaccount.google.com/permissions. To request deletion of any stored data, contact us below.
